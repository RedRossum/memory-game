# Игра «Memory Game» (Найди пару)

Интерактивная браузерная игра для тренировки памяти, в которой нужно находить пары одинаковых картинок.

## Как играть
1. Кликайте по закрытым карточкам, чтобы перевернуть их лицевой стороной вверх.
2. Открывайте карточки по очереди парами. Если картинки совпали, они остаются открытыми.
3. Если картинки не совпали, они закроются обратно через 1 секунду.
4. Игра завершается, когда вы найдёте все 8 пар карточек. Ваша цель — сделать это за минимальное количество ходов.

## Локальный запуск
Для запуска проекта на локальном сервере выполните команды в терминале:

```bash
pnpm install
pnpm run dev
```
